OVERVIEW

The Forensic Data Management System is a secure, offline, web-based medico-legal application designed to digitally manage forensic and medical examination records within Dhaka Medical College. The system replaces traditional paper-based workflows and physical registers with a controlled, auditable, and tamper-resistant digital system.

The system is deployed entirely offline inside the DMC forensic department and operates exclusively within a secured LAN environment, ensuring compliance with medico-legal confidentiality and data protection requirements.

This government-grade platform handles Post-Mortem Examination Records, Medical Examination Records, Consent Forms, Refusal Forms, and Age Determination Examination Records with comprehensive audit trails and role-based access control.

  • CLIENT

    Dhaka Medical College (DMC)

  • DEPARTMENT

    Forensic Medicine & Toxicology

  • PROJECT TYPE

    Government, Medico-Legal

  • DEPLOYMENT

    Offline Secure System

TECHNICAL ARCHITECTURE

Frontend: Next.js 15.3.1, React 19.0.0, TypeScript 5.x
Backend: ASP.NET Core 8.0 (Web API), Entity Framework Core 9.0.7
Database: Microsoft SQL Server (RDBMS)
Security: JWT Bearer Authentication, Role-Based Access Control (RBAC)

The system architecture consists of three layers: Client Layer (secure workstations accessing via standard web browsers), Application Layer (business logic, workflow validation, authorization enforcement), and Database Layer (centralized local database storing forensic records, user accounts, logs, and metadata).

All components are hosted within DMC's secured forensic infrastructure, ensuring complete offline operation with no internet dependency. The system features immutable approved records, read-only enforcement after submission, comprehensive audit logging, and automated scheduled database backups.
